# AI-assisted operating workflows

Run only the roles needed for the work. The human founder owns approval gates. Each workflow produces an evidence-linked hand-off; it does not authorise external actions.

## 1. New lead → qualified opportunity
1. Sales agent drafts qualification questions from supplied lead information.
2. Marketing agent checks positioning and factual claims.
3. Delivery agent estimates capacity and dependencies.
4. Finance agent prepares a non-binding cost/margin scenario if inputs are supplied.
5. COO consolidates options; CEO approves any offer, discount, or commitment.
6. A human sends all customer communications.

## 2. Product / project delivery
1. Product Manager drafts requirements, exclusions and acceptance criteria.
2. UX/UI proposes flows and responsive states.
3. Engineering Lead decomposes work and assigns technical role agents.
4. Engineers implement only in a development worktree after operator-approved writes.
5. QA independently runs checks and records defects.
6. Security reviews relevant trust boundaries and data flows.
7. CTO recommends release readiness; COO confirms delivery/handover readiness.
8. CEO gives final production approval. Human performs deployment.

## 3. Italian content release
1. Brand/localisation agent creates Italian copy using verified source facts.
2. Product/Legal coordinators flag meaning-sensitive text for qualified review.
3. Marketing checks claims, metadata and consistency.
4. QA checks truncation, forms, validation, responsive layouts and language consistency.
5. Founder approves publication.

## 4. Security / privacy concern
1. Security agent documents affected assets, evidence, severity and containment options.
2. CTO reviews technical response.
3. CEO is notified immediately for material risk.
4. Qualified counsel/DPO or other specialists are engaged where required.
5. Human operators execute containment and customer/regulator communications.

## 5. Finance / tax / legal matter
1. Finance Controller organises source records and a clearly labelled draft.
2. Accountant/Legal coordinator prepares questions and missing-evidence list.
3. Qualified commercialista or lawyer reviews and signs/advises as appropriate.
4. CEO approves business action. AI agents never file, sign or make professional determinations.

## 6. Incident / reliability
1. DevOps and Security agents gather read-only evidence and prepare a timeline.
2. CTO recommends containment, rollback and recovery options.
3. Human operator executes approved technical action; emergency containment follows the governance policy.
4. COO coordinates impact and customer updates; CEO approves material communications.
5. QA verifies recovery and a post-incident review records causes and actions.

## 7. Weekly leadership review
COO agent drafts operations, delivery and pipeline summary; CTO agent drafts engineering, quality and risk summary; Finance agent drafts reconciled figures only when source records are supplied. CEO agent may challenge assumptions and produce decision briefs. The human CEO sets priorities and records decisions.

## 8. Hiring / capacity
People agent drafts a capability gap and role brief; COO checks workload; CTO checks technical needs; Finance checks affordability. The founder alone approves hiring and any engagement terms.
