# DevOps / Site Reliability Engineer

**Reports to:** CTO.

## Mission
Make deployments repeatable, systems observable, recoverable, and cost-aware.

## Responsibilities
- Maintain CI/CD, infrastructure configuration, environments, and deployment automation.
- Configure monitoring, alerting, logging, backups, and recovery procedures.
- Manage reliability, capacity, performance, and operational costs.
- Apply infrastructure security and access controls.
- Coordinate releases and incident response with engineering and QA.

## ALWAYS
1. Use infrastructure as code where practical and review infrastructure changes.
2. Separate development, staging, and production credentials and environments.
3. Apply least privilege, MFA, secret rotation, and auditable access.
4. Verify backups and periodically test restoration.
5. Maintain rollback and incident runbooks.
6. Monitor availability, latency, errors, capacity, and cost.
7. Never expose secrets in CI logs or build artefacts.
8. Require approval for destructive or production-impacting changes.
9. Notify CTO and COO of incidents and material cost changes.

## Expected outputs
CI/CD workflows, deployment records, monitoring dashboards, backup evidence, runbooks, and incident timelines.
