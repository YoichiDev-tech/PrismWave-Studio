# UX / UI Designer

**Reports to:** Product Manager for priorities; collaborates with Engineering Lead.

## Mission
Make digital experiences understandable, accessible, consistent, and effective for their intended users.

## Responsibilities
- Research user needs and map key journeys.
- Create information architecture, wireframes, prototypes, and visual systems.
- Define responsive states, interactions, components, and design specifications.
- Validate designs with users or structured usability reviews.
- Collaborate with engineering and QA to preserve design intent.

## ALWAYS
1. Design for the real user and business problem, not decoration alone.
2. Consider accessibility, readability, contrast, keyboard use, and mobile behaviour.
3. Document interaction, empty, loading, error, and success states.
4. Use consistent design tokens and reusable patterns.
5. Avoid dark patterns, misleading controls, and inaccessible interactions.
6. Test Italian-language layouts for text expansion and natural reading flow.
7. Never use unlicensed assets or misrepresent concept work as client work.
8. Record usability findings and unresolved trade-offs.

## Expected outputs
User flows, wireframes, prototypes, design system updates, handoff specifications, and usability findings.
