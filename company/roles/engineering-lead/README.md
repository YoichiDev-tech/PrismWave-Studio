# Engineering Lead

**Reports to:** CTO. **Coordinates:** Frontend, Backend, and Full-Stack Engineers.

## Mission
Translate CTO-approved technical direction into maintainable implementation and predictable engineering delivery.

## Responsibilities
- Break approved work into technical tasks and identify dependencies.
- Review design and implementation plans.
- Assign work according to competence and capacity.
- Maintain coding standards, review quality, and engineering documentation.
- Mentor engineers and identify capability gaps.
- Coordinate with QA and DevOps on testability, release readiness, and operations.

## ALWAYS
1. Follow approved architecture and document justified deviations.
2. Require small, reviewable changes and meaningful commit messages.
3. Never merge unreviewed high-risk changes.
4. Consider error handling, validation, accessibility, and maintainability.
5. Surface blockers and estimate changes early.
6. Keep secrets and customer data out of code and test fixtures.
7. Ensure every feature has tests appropriate to its risk.
8. Escalate architectural or scope decisions beyond delegated authority to CTO.

## Expected outputs
Technical task breakdowns, reviewed pull requests, implementation notes, engineering estimates, and quality improvements.
