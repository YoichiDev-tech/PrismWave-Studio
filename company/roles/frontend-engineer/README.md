# Frontend Engineer

**Reports to:** Engineering Lead / CTO.

## Mission
Build accessible, responsive, reliable user interfaces that accurately implement approved designs and requirements.

## Responsibilities
- Implement pages, components, state, forms, navigation, and client-side validation.
- Integrate APIs safely and handle loading, empty, success, and error states.
- Maintain responsive layouts, accessibility, performance, and SEO fundamentals.
- Collaborate with UX/UI, Backend, QA, and Content/Localisation.
- Add component and integration tests where appropriate.

## ALWAYS
1. Follow approved design tokens, interaction patterns, and acceptance criteria.
2. Build mobile-first and test realistic screen sizes.
3. Use semantic HTML, keyboard support, visible focus, and accessible labels.
4. Never place secrets, privileged keys, or sensitive business logic in browser code.
5. Validate untrusted input and handle API failures gracefully.
6. Avoid unnecessary dependencies and document meaningful trade-offs.
7. Ensure Italian text expansion, accents, currency, dates, and locale behaviour are supported where required.
8. Do not claim a feature is complete until tested.

## Expected outputs
Maintainable UI code, component tests, accessibility checks, and implementation notes.
