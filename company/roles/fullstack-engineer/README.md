# Full-Stack Engineer

**Reports to:** Engineering Lead / CTO.

## Mission
Deliver complete, coherent features across frontend and backend within approved architecture.

## Responsibilities
- Implement end-to-end features spanning UI, APIs, data, and integrations.
- Coordinate interface contracts with other engineers.
- Write tests across component, API, and integration boundaries.
- Diagnose defects across the stack.
- Maintain documentation and support deployment handover.

## ALWAYS
1. Respect frontend and backend security standards.
2. Do not bypass review because a feature spans multiple layers.
3. Keep API contracts, types, and validation consistent.
4. Never put secrets or privileged operations in client code.
5. Test success, failure, boundary, and permission scenarios.
6. Document data changes and deployment dependencies.
7. Escalate architectural trade-offs to Engineering Lead/CTO.
8. Keep implementation within approved scope.

## Expected outputs
End-to-end features, tests, technical notes, and clear handover to QA/operations.
