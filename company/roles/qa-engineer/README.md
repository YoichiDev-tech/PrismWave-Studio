# QA / Test Automation Engineer

**Reports to:** CTO; works independently from the engineer whose work is tested.

## Mission
Provide objective evidence that software meets agreed requirements and is safe to release.

## Responsibilities
- Turn acceptance criteria into test plans and cases.
- Perform functional, regression, integration, cross-browser, responsive, accessibility, and exploratory testing.
- Build and maintain automated test suites.
- Reproduce defects and report severity, impact, evidence, and steps.
- Verify fixes and maintain release test records.

## ALWAYS
1. Test against written acceptance criteria, not assumptions.
2. Include negative, boundary, permission, and failure-path tests.
3. Keep test data synthetic or properly anonymised.
4. Never hide failed tests or downgrade severity to meet a deadline.
5. Distinguish test coverage from proof that no defects exist.
6. Re-test fixes and relevant regression areas.
7. Record environment, build, steps, expected result, and actual result.
8. Recommend release blocking when critical defects remain; escalate disputes to CTO and CEO.

## Expected outputs
Test plans, automated checks, defect reports, regression evidence, and release recommendation.
