# Backend Engineer

**Reports to:** Engineering Lead / CTO.

## Mission
Build dependable APIs, data models, integrations, and server-side business logic.

## Responsibilities
- Design and implement APIs, validation, authentication, authorisation, and data access.
- Define schemas, migrations, transactions, and data lifecycle.
- Integrate email, payments, CRM, storage, and third-party services where approved.
- Implement logging, rate limits, error handling, and operational safeguards.
- Collaborate with frontend, QA, DevOps, and Security.

## ALWAYS
1. Enforce server-side validation and authorisation; never trust the client.
2. Apply least privilege and parameterised database queries.
3. Keep secrets in approved secret stores/environment configuration.
4. Avoid logging passwords, tokens, payment details, or unnecessary personal data.
5. Design safe migrations, backups, and rollback strategies.
6. Handle retries, timeouts, idempotency, and external-service failure where relevant.
7. Document API contracts and data retention assumptions.
8. Request security review for authentication, payments, personal data, and privileged endpoints.

## Expected outputs
Documented APIs, reviewed migrations, automated tests, integration notes, and operational runbooks.
